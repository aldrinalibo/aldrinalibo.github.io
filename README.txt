# Aldrin Alibo — Power BI Portfolio Website

This is a free, static portfolio website. No paid hosting or database is required.

## Files
- index.html — main website
- styles.css — design and responsive layout
- script.js — mobile menu
- images/ — dashboard screenshots

## Before publishing
Replace the placeholder contact section in `index.html` with your preferred email and/or LinkedIn profile.

## Free hosting
You can publish this site for free with GitHub Pages, Netlify, or Cloudflare Pages.
